# 컴구 정리노트 · 소스 폴더

| 파일 | 내용 | 언제 고쳐? |
|---|---|---|
| notes.json | 📒 **노트 내용 전부** (장 → 파트 → 블록, 블록 하나 = 한 줄) | 노트 고칠 때 ⭐ |
| app.js | 퀴즈 문제(QS_1~6) · 실습 · 화면 · 편집 모드 | 퀴즈 · 실습 고칠 때 |
| style.css | 색 · 글꼴 · 레이아웃 | 디자인 바꿀 때 |
| index.html | 화면 뼈대 + 노트 비상용 사본 | 거의 안 건드림 |
| images.js | 사진(base64) | 거의 안 건드림 |

## 깃허브에 올리기
이 폴더 파일 6개를 저장소에 그대로 올리고 Pages를 켜면 끝.
편집 모드(, 3번 → 0817) → 🐙 토큰 연결 → 💾 저장하면 notes.json이 바로 커밋돼요.

## notes.json vs index.html 속 노트
- 깃허브 사이트에서는 항상 **notes.json**을 읽어요 (진짜).
- index.html 안의 noteData는 내 컴퓨터에서 파일로 열 때 쓰는 **비상용 사본**이에요.

## 블록 종류
index.html의 noteData 바로 위 주석에 안내표가 있어요.
굵게: **글자**

## 퀴즈 형식
app.js에서 `const QS_1` ~ `const QS_6` 검색.
{s:파트id, q:문제, ch:[정답(첫 번째), 오답...], w:해설, ex:1(시험각), ox:1(OX), pr:1(교재 연습문제), img:사진키}
